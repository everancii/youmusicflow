# Plan 03-02: Now-Playing Pipeline

## Objective
Track title/artist flows preload → IPC → tray tooltip/title + optional desktop notification, gated by a new `showNotifications` setting.

## Context
- RESEARCH.md: poll `navigator.mediaSession.metadata` (1s) in preload — no DOM scraping. Snapshot for `IPCEventNames` must be updated (`jest -u`, verify diff).
- Tray instance lives in main.ts closure — pass it into the now-playing wiring.

## Tasks

### Task 1: IPC event + preload poller
- `src/types/ipc.ts`: add `NOW_PLAYING: 'now-playing'` (match existing naming style — check file first). Update snapshot deliberately.
- `src/client/index.ts`: `setInterval(1000)` reading `navigator.mediaSession.metadata` (`title`, first of `artist`); keep last-sent pair; on change → `ipcRenderer.send(NOW_PLAYING, { title, artist })`. Guard nulls.

### Task 2: Main-side handler module
- Create `src/main-process/nowPlaying.ts`:
  - Pure exports for testability: `formatTooltip(title, artist)` → `"Title — Artist"`; `truncate(s, n=30)`; `shouldNotify(prevTitle: string | null, nextTitle: string)` → prev !== null && prev !== next.
  - `registerNowPlaying({ tray })`: `ipcMain.on(NOW_PLAYING, ...)` → validate strings, `tray.setToolTip(...)`, macOS `tray.setTitle(truncate(title))`, and if `shouldNotify` + `getSetting('showNotifications')` → `new Notification({ title, body: artist, silent: true }).show()`.
- Wire in `main.ts` after tray creation.
- Create `spec/main-process/nowPlaying.spec.ts`: unit tests for the pure functions (mock electron/electron-store as needed, or keep pure fns import-safe by isolating electron imports).

### Task 3: showNotifications setting
- `settings.ts`: add `showNotifications: boolean` to `AppSettings`, schema (default `true`), `isValidSetting` boolean case.
- `spec/tools/settings.spec.ts`: add showNotifications cases.
- `src/settings/index.html` + `renderer.js`: checkbox wired like existing toggles (settingsAPI.updateSetting). No main-side reaction needed in registerIpc beyond the store write (setting is read live at notify time).

## Acceptance
- `npm run build` clean; all suites pass; ipc snapshot diff = only NOW_PLAYING.
- Grep: `mediaSession` in src/client/index.ts; `setToolTip` in nowPlaying.ts; `showNotifications` in settings.ts, index.html, renderer.js.
- Conventional commits.
