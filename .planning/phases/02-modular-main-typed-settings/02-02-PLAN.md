## Task 1 — Typed settings store + validator (CODE-02)

In `src/tools/settings.ts`:
- `import Store, { Schema } from 'electron-store'`; declare `const schema: Schema<AppSettings> = {...}` (same runtime values, drop `as any`).
- `getSettings()` → `return store.store` or per-key gets — no `@ts-ignore` anywhere.
- `updateSetting<K extends keyof AppSettings>(key: K, value: AppSettings[K])` and `getSetting<K extends keyof AppSettings>(key: K): AppSettings[K]`.
- Add pure `export function isValidSetting(key: unknown, value: unknown): key is keyof AppSettings` — whitelist per key: `windowPosition` ∈ enum list, the four boolean keys require `typeof value === 'boolean'`. Unknown key → false. (Keep it dependency-free so Jest node env can test it.)
- Grep-check the file for `@ts-ignore` → must be zero. Update `src/main.ts`/callers if the stricter generic signatures surface type errors (fix call sites, don't loosen types).

## Task 3 — Preload + hardened settings window (CODE-03)

- New `src/settings/preload.ts`:
  ```ts
  import { contextBridge, ipcRenderer } from 'electron'
  contextBridge.exposeInMainWorld('settingsAPI', {
    getSettings: () => ipcRenderer.invoke('get-settings'),
    getAppVersion: () => ipcRenderer.invoke('get-app-version'),
    getPlatform: () => ipcRenderer.invoke('get-platform'),
    updateSetting: (key, value) => ipcRenderer.send('update-setting', key, value)
  })
  ```
- `src/main-process/createSettingsWindow.ts` webPreferences → `contextIsolation: true, nodeIntegration: false, preload: path.join(__dirname, '../settings/preload.js')` (path is relative to `app/main-process/` — verify the compiled location before finalizing).
- `src/settings/renderer.js`: delete `require('electron')`; replace `ipcRenderer.invoke('get-settings')` → `window.settingsAPI.getSettings()` etc., and each `ipcRenderer.send('update-setting', k, v)` → `window.settingsAPI.updateSetting(k, v)`. `window.close()` stays (DOM API).
- Build & verify `app/settings/` contains: index.html, style.css, renderer.js (copied) AND preload.js (compiled) — confirm copy-assets did not remove it.
