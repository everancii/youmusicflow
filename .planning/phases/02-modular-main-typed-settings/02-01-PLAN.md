- **positionWindow.ts**: export `WINDOW_WIDTH = 375`, `WINDOW_HEIGHT = 667`. Export `updateWindowPosition({ mainWindow, tray, offset })` containing the exact Windows branch and generic branch from main.ts:158-244 (verbatim, only swapping the literals for the constants). Export a small `positionOnTrayClickMac({ mainWindow, tray, offset })` for the macOS tray-click formula — it MUST reuse `WINDOW_WIDTH` (replaces the hardcoded `375` at main.ts:252).
- **createMainWindow.ts**: export `createMainWindow()` returning `{ mainWindow, updateDockVisibility }`. Contains the BrowserWindow ctor (main.ts:60-75), `setLoginItemSettings`, `updateDockVisibility`, initial dock-visibility apply, `loadURL`, `injectCSS` + its 4 webContents listeners, and the blur-hide handler. - **registerShortcuts.ts**: export `registerMediaKeys(mainWindow)` and `unregisterMediaKeys()` (verbatim from 265-285).
- **createSettingsWindow.ts**: export `createSettingsWindow(app)` that registers the `app.on('open-settings')` handler (main.ts:293-319) creating/focusing the settings BrowserWindow. Keep webPreferences exactly as-is for now (contextIsolation:false) — CODE-03 hardens it in plan 02-02.

Preserve `no-semicolon / single-quote` Prettier style.

## Task 3 — Rewrite main.ts as orchestrator

`main.ts` keeps: electron imports it still needs, the darwin app-name block, single-instance lock + `second-instance`, and `window-all-closed`. The `ready` handler becomes:
1. darwin dock icon apply (keep inline — it's pre-window)
2. `const { mainWindow, updateDockVisibility } = createMainWindow()`
3. build `offset` via offsetCalclator
4. `Menu.setApplicationMenu(...)` (unchanged)
5. `const updateWindowPosition = () => positionWindow.updateWindowPosition({ mainWindow, tray, offset })`
6. `const tray = createTray({ onClick, onRightClick })` where onClick uses `positionOnTrayClickMac` on macOS else `updateWindowPosition`, then `mainWindow.show()`; onRightClick pops the context menu
7. `updateWindowPosition()` initial
8. `if (getSetting('enableMediaKeys') !== false) registerMediaKeys(mainWindow)`
9. `createSettingsWindow(app)`
10. `registerIpc({...})`

Order note: tray needs `updateWindowPosition`, which needs `tray`. Resolve exactly as today — declare `tray` with `let`, define `updateWindowPosition` as a closure referencing `tray`, then assign `tray = createTray(...)` before calling `updateWindowPosition()`. Behavior is identical to current code.
