# Plan 03-01: Navigation Guard + Offline Retry

## Objective
Window never leaves the YTM/auth origin set; new-window attempts go to the default browser; failed loads show a retry page instead of a blank transparent window.

## Context
- RESEARCH.md: allowlist hosts, ERR_ABORTED (-3) guard, `isMainFrame` guard, copy-assets whitelist extension, preload `appShell.retry` bridge.
- Main window preload is `app/client/index.js` (from `src/client/index.ts`) and persists across navigations — reuse it for the retry bridge.

## Tasks

### Task 1: Navigation policy module + tests
- Create `src/tools/navigationPolicy.ts`: `ALLOWED_HOSTS` set (music.youtube.com, accounts.google.com, accounts.youtube.com, consent.youtube.com, consent.google.com, www.youtube.com, myaccount.google.com) + `export const isAllowedNavigation = (url: string): boolean` — parse with `new URL()`, require http/https, hostname in set; malformed URL → false.
- Create `spec/tools/navigationPolicy.spec.ts` (node env, no electron): allowed cases (player URL, accounts.google.com login), rejected cases (twitter share link, `javascript:` scheme, garbage string, sub-path of evil host like `music.youtube.com.evil.com`).

### Task 2: Wire guards into createMainWindow
- In `createMainWindow.ts`: `mainWindow.webContents.setWindowOpenHandler(({ url }) => { if (!isAllowedNavigation(url)) { shell.openExternal(url); return { action: 'deny' } } return { action: 'allow' } })` — actually deny+openExternal for allowed-host popups too? No: allowed hosts may open popups for auth — return `{ action: 'allow' }` for allowed, deny+external otherwise.
- `will-navigate`: if target URL not allowed → `event.preventDefault()` + `shell.openExternal(url)`.
- `did-fail-load`: guard `isMainFrame && errorCode !== -3` → `mainWindow.loadFile(path.join(__dirname, '../offline/offline.html'))`.

### Task 3: Offline page + retry plumbing
- `src/offline/offline.html`: dark, minimal, inline CSS matching app aesthetic; message + Retry button calling `window.appShell.retry()`; `window.addEventListener('online', () => window.appShell.retry())`.
- `src/client/index.ts`: add `contextBridge.exposeInMainWorld('appShell', { retry: () => ipcRenderer.send('retry-load') })`.
- `registerIpc.ts`: `ipcMain.on('retry-load', () => mainWindow.loadURL('https://music.youtube.com'))`.
- `copy-assets.js`: extend to copy `src/offline/offline.html` → `app/offline/offline.html` (keep settings whitelist untouched).

## Acceptance
- `npm run build` clean; `app/offline/offline.html` exists after build.
- All tests pass incl. new navigationPolicy spec.
- Grep: `setWindowOpenHandler` and `will-navigate` present in createMainWindow.ts; `errorCode` guard present.
- Conventional commit per logical unit.
